## Quick Reference (App Directory)

### Essential Commands

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Run high-speed static code analysis (Oxlint)
npm run lint

# Build production bundle
npm run build

# Preview production build locally
npm run preview

# Run mock REST API (db.json)
npm run start
```

### Environment Configuration
Copy `.env.example` to `.env` and configure your Supabase and ImgBB credentials:
```bash
cp .env.example .env
```
